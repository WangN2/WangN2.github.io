1. 为什么要做全程复盘

模块级测试通过、集成后失败，原因通常只有两类：单位或坐标系没对齐，或者时间上不是同一时刻的数据。这两类问题在单个模块内部永远测不出来，因为每个模块自己都是自洽的。

所以复盘要回答的不是「哪一步算错了」，而是「这一步用的数据，是不是它以为的那个东西」。

2. 八步时序

步动作输入 → 输出失败会怎样
1到位工位坐标 → 停在视野内停歪：观测失败或精度下降
2观测图像 → 标签在相机系的位姿重试后放弃，不猜
3搬进基座系＋外参、＋末端位姿 → 盘位姿外参过期：位姿系统性偏移
4重算站位＋示教文件 → 四个目标点轴反向：直接拒绝
5预检目标序列 → 可达性结论超限：不试跑
6进孔目标点 → 末端到位超差：停
7判定主驱动角 → 是否吃上槽落区外：停住，不硬来
8记录日志 → 可复盘的证据记录不全：无法归因

4. 四个衔接处的坑

坑症状怎么查
时间戳不一致静止时很准，一动就偏；盘越动越明显比对手眼观测与机器人位姿的时间戳，差值要小于运动导致的位移容差
坐标系搞混平移看着对、方向随姿态旋转；换个姿态就错把同一点在三个系里各打印一次，逐个比对
外参过期某天开始系统性偏移，且偏得一致查标定日期与最近一次机械改动的时间先后
延迟与缓冲偶尔抓偏，重跑一次就好看各环节延迟分布，而不是平均值

四个坑里前三个都表现为「偏移」，但规律不同：时间戳问题是随速度变化，坐标系问题是随姿态变化，外参问题是随时间突变。会看这三条规律，排查能省掉一大半时间。

5. 失败怎么归类

不归类就会陷入「再试一次」。四类失败的入口完全不同：

类别典型现象先查
观测失败没解出标签，或重投影误差超限光照、遮挡、标签尺寸、内参
几何失败解出了盘位姿，但目标点不对外参、示教文件的坐标系、轴方向
执行失败目标点对，但末端没走到可达性、限位、伺服误差、路径代价
判定失败走到了，但没吃上槽入槽深度、爪指状态、撑开区间

这四类的比例本身就很有信息量：观测失败多，说明工位设计有问题；判定失败多，说明末端参数没调好；如果四类平均分布，多半是整条链路缺少标定。

6. 一次运行该留下什么

能复盘的最小集合，比想象中少，但一条都不能缺：

  • 时间戳：每个环节的输入时刻与输出时刻，不只是总耗时；
  • 坐标系名：每个位姿都要标清楚在哪个系里，别靠注释；
  • 参数版本：外参的标定日期、示教文件的版本、权重或门限的取值；
  • 拒绝理由：失败时给出的具体原因（轴反向、倾角超限、落区外），而不是一个布尔值。

最后一条最容易被简化。程序里写 return false 很省事，但半年后你只知道「那次失败了」，不知道失败在哪一环。

7. 收尾：哪些是模型，哪些是测量

回头看这八篇，内容其实分成两类：

靠推导靠测量
正运动学、雅可比、舵轮逆解外参、示教站位、入槽深度
刚体变换链、代价场公式门限值（10°、21 mm、±60 mm）
AX = XB 的推导哪些姿态算「足够多样」

左边可以写对，右边只能测对。这也解释了这个系列为什么反复强调边界：模型负责把问题变小，测量负责给出可信的数。两者缺一个，链条就是断的。

至于大模型——它在料盘那篇的第 10–15 节里已经说清楚了：它是把「想法」变成「可运行代码」的加速器，不是把「代码」变成「可信结果」的替代品。后者只能靠测量，而测量正是这八篇里最枯燥、也最值钱的部分。
