相机标定

标定不是让重投影误差变小，是让参数对得上物理世界。这两件事经常不一致。

2026-11-08约 6 分钟标定全系列 ›

第一次做标定最容易陷入的困惑是：跑完了，RMS 0.2 像素，看起来很完美，但一上机器人，板子的高度就是差几厘米。这篇把参数的作用讲透，再说清楚为什么会这样。

1. 标定在解一个什么问题

相机做的事只有一件：把三维点压到二维像素上。

u = fx · (X/Z) + cx　　v = fy · (Y/Z) + cy

这就是针孔模型。X/Y/Z 是点在相机坐标系里的位置，u/v 是它落在哪一列哪一行像素上。

标定就是反着来：我知道一堆三维点的真实位置（标定板上的角点），也知道它们在图像里的像素位置（检测出来的），求中间那组参数。

所以标定的本质是最优化——找一组参数，让「按公式算出来的像素位置」和「实际检测到的像素位置」尽可能地接近。这个差值叫重投影误差。

2. 四个内参，各管一件事

内参只有四个数，但每一个错了，画面会以完全不同的方式歪。

参数物理含义标错的表现
fx水平方向焦距（像素）整体缩放：画面里的东西一起变大或变小
fy垂直方向焦距（像素）只在纵向缩放；与 fx 不等说明像元不是正方形
cx主点横坐标整幅画面横向平移
cy主点纵坐标整幅画面纵向平移

三个能立刻玩出来的结论：

一、cx/cy 是整体平移，fx/fy 是整体缩放。这两类误差靠看平均值就能发现——所有点朝同一个方向偏，就是主点；所有点从中心散开或聚拢，就是焦距。

二、焦距和距离是同一件事的两种解释。板子看起来大了，可能是相机焦距大，也可能是板子离得近。单目里这两者不可分——这就是尺度模糊。所以标定板的尺寸必须准确。

三、一像素很贵。在 0.7 m 处，1 px 大约是 1.2 mm。十来个像素的误差，落到抓取上就是一两厘米的偏差。

3. 畸变：为什么边缘比中心错得多

真实镜头不是理想针孔，直线会被拍弯。主流模型是这样修正的：

x' = x·(1 + k1·r² + k2·r⁴)　　r² = x² + y²

k1 管主要的弯曲方向：负值是桶形（边缘往外鼓），正值是枕形（边缘往里收）。k2 修高阶残差。

注意这个式子里的 r——畸变随半径四次方增长，所以画面中心几乎是线性的，越往外错得越快。这解释了那条经验：板子只放画面中央，畸变系数根本没被约束住，标出来的 k1 是猜的。

把沙盘里的 k1 从 -0.28 拖到 0，你会看到橙色的网格变直，而蓝点还是弯的——真实相机就是弯的，把 k1 设成 0 就是用错误模型去解释它。

4. 外参：把相机坐标搬到机器人坐标

内参描述相机自己，外参描述它装在哪。一个刚体变换，六个自由度：三个旋转、三个平移。

P_robot = R · P_camera + t

外参标错的典型表现不是画面歪，而是整个世界一起偏：板子整体高了几厘米、料盘整体远了十厘米。因为它是一个作用在所有观测上的同一个变换。

这也是它比内参更难查的原因——内参错了，不同位置的误差不一样，你能看出来是畸变；外参错了，所有点一致地偏，看起来反而"很稳定"。

5. 张正友：为什么一块平面板就够

一张平面标定板在同一姿态下只能提供一个单应矩阵（八自由度），但相机有五个内参加畸变。单张不够，多张不同姿态就够。

张正友方法的价值在于：它证明了不需要三维标定物。一张打印的棋盘格，从十几个角度拍，就能同时解出内参和每张图的位姿。

两步走：先用闭式解（线性代数）拿到初值，再用非线性最小二乘（Levenberg-Marquardt）精化。前者保证不跑偏，后者保证精度。

6. 成熟算法与工具

工具适合要点
OpenCV calibrateCamera最通用棋盘格 / 圆点板 / ChArUco；返回值里带 RMS
OpenCV solvePnP外参与位姿已知 3D-2D 对应求位姿；SOLVEPNP_IPPE 适合平面
MATLAB Camera Calibrator教学与验证交互看残差分布，适合判断"哪里错了"
Kalibr多相机 + IMU连续时间标定，能同时解时间偏移
ROS camera_calibration在线快速标定适合现场，精度一般
ChArUco / AprilTag（OpenCV contrib）遮挡、部分可见带 ID，单张可解位姿
COLMAP无标定板自标定从普通照片重建，适合大场景
HALCON calibrate_cameras工业产线商业库，配套标定板精度高

新手建议：先用 OpenCV 走一遍完整流程，再用 MATLAB 的残差可视化核对一遍。两个结果差得多，说明数据有问题，不是算法有问题。

7. 为什么 RMS 合格了还会偏

这是上一轮最折磨人的地方，也是这篇最想说清的一点。

原因一：外参和板子位姿是一起优化的。内参固定后，每张图的板子位姿和外参是同一组未知量。模型完全可以通过调整板子位姿，把外参的偏差吸收掉。你得到的是一个自洽的解，不是一个正确的解。RMS 小，只证明模型内部一致。

原因二：单个姿态只能定两个旋转自由度。把板子放在同一个位置、同一个角度，无论怎么标，绕板面法线的那一维（偏航）都没有信息。必须换倾斜方位、换距离，才能把它约束住。

原因三：用卷尺量绝对高度，会和俯仰耦合。高度差几毫米，既可以是整体抬高，也可以是一个小角度旋转造成的。两种解释对同一个测量是等价的，所以你永远调不平——这不是手法问题，是观测量不足以区分。

正确的做法是：用水平仪测角度，不用卷尺测高度。角度是独立的观测量，高度不是。

8. 验收：不要只看 RMS

三个层次的验收，从弱到强：

一、重投影误差。必要不充分。工程上常看角点数（≥28）和 RMS（≤0.8 px），但这只是入门门槛。

二、留出验证。用没参与标定的点或位姿做检验。标定集和验证集的残差同量级，才算没有过拟合。

三、物理任务。让机器人去指一个已知点、抓一个已知尺寸的块、把一个物体放到另一个物体上。这是唯一能证明参数对得上物理世界的检验。

一句话：标定的产出不是一个变换矩阵，是矩阵加上它的不确定度。没有不确定度的标定，验收时只能凭感觉。

9. 收尾

回到开头那句：标定不是让重投影误差变小，是让参数对得上物理世界。

这两个目标在数据充分时是一致的，在数据不足时会分道扬镳——而现场标定几乎总是数据不足。所以与其追求更小的 RMS，不如先问：我的数据覆盖了哪些自由度？哪些方向根本没人约束？

想清楚了再去拍板子，比拍完两百张再返工要省得多。
