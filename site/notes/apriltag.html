1. AprilTag 是什么

AprilTag 是一种视觉基准标记（fiducial marker）系统。标签外圈有黑色边框，内部是黑白编码格。把已知尺寸的标签贴在工装板或工作台上，相机检测到它后，可以得到标签相对相机的位置与朝向，也就是六自由度（6DoF）位姿。

标签角点的 3D 几何 + 图像中的 2D 角点 + 相机内参 → 标签相对相机的 R、t

典型链路是：工装板贴标签 → 相机拍摄 → 检测 ID 并解算位姿 → 通过相机外参转换到机器人坐标系 → 引导上料、插接或精对准。

2. tag36h11：36 位编码与汉明距离

AprilTag 有多个编码家族（family），tag36h11 是常用的标准家族之一。名字可以拆成两部分：36 表示 6×6 数据区共有 36 个编码位，h11 表示合法编码之间的最小汉明距离为 11。

汉明距离就是两段二进制编码有多少位不同。距离越大，两张标签越不容易被相互认错。

家族数据网格最小汉明距离理论纠错位数标签数量
tag16h54×45230
tag25h95×59435
tag36h116×6115587
理论最多纠错位数 = ⌊(最小汉明距离 − 1) / 2⌋ = ⌊(11 − 1) / 2⌋ = 5

在理想采样、四边形与朝向已经正确确定的前提下，与正确编码相差不超过 5 位时，最近邻解码仍能找回它。这不等于“任意遮挡或模糊 5 格都一定能检测成功”：角点提取、分辨率、运动模糊、反光和光照都会在解码之前影响结果。

tag36h11 提供 587 个 ID，数量和容错能力适合多工位场景。代价是数据格更多；远距离或小尺寸成像时，每个格子分到的像素更少。

动手体验：在解码实验中旋转标签、翻转格子或注入 1–6 位错误，观察最近编码、汉明距离、朝向和接受阈值如何变化。

3. 一帧图像如何变成 ID 与位姿

  1. 寻找四边形。检测器在灰度图中寻找明暗边缘与黑色边框，拟合候选四边形并细化角点。
  2. 采样数据格。利用四边形的透视关系，把标签内部映射回规则网格，在 6×6 数据区读取黑白位。黑框外的白色安静区有助于把标签与背景分开。
  3. 旋转匹配与纠错。将读到的编码按四种朝向与家族编码比较，选择汉明距离最近的合法 ID，同时确定标签朝向。
  4. 解算位姿。已知标签四个角点在标签平面上的 3D 坐标，再对应到图像中的 2D 坐标，通过 PnP 求旋转 R 和平移 t。

检测结果里的 hamming 和 decision_margin 分别反映编码纠错程度与黑白采样置信度。它们是很有用的质量门限，但不能直接当作位姿精度；位姿还应检查重投影误差和多帧稳定性。

4. 为什么 PnP 离不开内参与标签尺寸

针孔相机用内参矩阵 K 描述焦距和主点。归一化后的相机坐标才能与像素坐标相互转换：

u = fx · X/Z + cx
v = fy · Y/Z + cy

标签中心为原点、边长已知时，四个角点在标签坐标系中的位置就确定了。求解器要寻找一组 R、t，使这些 3D 角点投影后尽量落在检测到的 2D 角点上。

目标：最小化 Σ ‖project(K, R · Pᵢ + t) − pᵢ‖²

这里的边长通常指黑色外框的完整边长，不包含额外留白。尺寸填错会直接带来尺度和深度误差；内参或畸变处理不准确，则会让角点对应关系本身产生系统误差。

平面靶标在近正面、远距离或角点噪声较大时，还可能出现姿态歧义：两种不同的倾斜与深度组合产生相近投影。工程上可结合 IPPE 平面求解、多帧滤波、多标签或运动先验提高稳定性。

动手体验：在位姿实验中调整 XYZ、三轴旋转、焦距、标签尺寸和角点噪声。实验室用四角点求平面单应并分解 R、t，橙色虚线会显示解算后的重投影。

5. pupil-apriltags 的正确调用方式

pupil-apriltags 是 AprilTag 3 的 Python 绑定，包名与导入名不同：安装时使用 pupil-apriltags，代码中导入 pupil_apriltags。不要与另一个名为 apriltag 的 Python 包混用 API。

import cv2
from pupil_apriltags import Detector

detector = Detector(families="tag36h11")
gray = cv2.cvtColor(frame, cv2.COLOR_BGR2GRAY)

detections = detector.detect(
    gray,
    estimate_tag_pose=True,
    camera_params=(fx, fy, cx, cy),  # 与去畸变后的图像一致
    tag_size=0.16,                   # 黑框边长，单位：米
)

for d in detections:
    print(d.tag_id, d.hamming, d.decision_margin)
    print(d.center, d.corners)
    print(d.pose_R, d.pose_t)       # T_cam_tag 的 R 与 t

只有请求位姿估计并传入正确的内参与物理尺寸，pose_R、pose_t 才有意义。pose_t 与 tag_size 使用相同的长度单位；上例中是米。

6. 从相机坐标系到机器人坐标系

检测器给出的是 T_cam_tag：标签在相机坐标系下的位姿。若已通过手眼或安装标定得到 T_base_cam，则：

T_base_tag = T_base_cam · T_cam_tag

如果标签与整块工装板之间还有固定安装关系 T_tag_board，继续右乘即可得到工装板在机器人基座坐标系中的位姿：

T_base_board = T_base_cam · T_cam_tag · T_tag_board

变换顺序和方向必须与所用库的约定一致。把“相机在基座中的位姿”和“基座在相机中的位姿”混用，是现场最常见的系统错误之一。

标签检测 → 质量门限 → 6DoF 位姿 → 外参变换 → 工装板定位 → 上料 / 插接 / 精对准

7. 工程落地时，别只看“检测到了”

检查项为什么重要
内参与畸变决定像素角点如何变成空间射线；标定分辨率和去畸变流程要一致。
标签实际尺寸直接决定位姿尺度与深度，打印后要实测，不能只相信设计值。
像素占据与光照标签太小、运动模糊或反光时，即使外框可见，数据格也可能不可靠。
Hamming 与 decision margin用于拒绝纠错过多或黑白对比不足的检测，阈值应结合数据验证。
重投影与多帧稳定性用于发现角点异常、平面姿态跳变和偶发错误位姿。
相机外参与时间同步相机或机器人运动时，外参方向、标定误差和时刻错位都会进入最终位姿。

一句话总结

概念要点
AprilTag视觉基准标记系统；检测标签后可解算其相对相机的 6DoF 位姿。
tag36h116×6 数据区、587 个 ID、最小汉明距离 11，理想条件下最多纠正 5 位。
