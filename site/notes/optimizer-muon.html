优化器与 Muon

优化器之间的差别，可以从更新量如何缩放来理解。Muon 特别之处，是调整二维更新矩阵的谱，而不是直接测量损失曲率。

1. 先看都有哪些优化器

梯度是一个向量，但「往哪走、走多远」取决于你怎么定义距离。换了尺子，最速下降的方向就变了。按这把尺子分类，现有的优化器大致是这么几档：

尺子代表更新式
欧氏距离SGD、动量、NesterovΔ = −η·g
逐坐标缩放AdaGrad、RMSProp、Adam / AdamW、LionΔ = −η·m / (√v + ε)
行与列的低秩近似Adafactor、Shampoo、SOAP用 Kronecker 因子做预条件
矩阵的谱结构MuonΔ = −η·U Vᵀ
二阶曲率估计Sophia、K-FAC用曲率替换学习率

AdamW 仍然是默认答案。想换的动力一般只有三个：省显存、省算力，或者在大规模上拿到更好的缩放。

Muon 属于第四类。它不问「每个参数该走多大」，它问「这张权重矩阵的更新，在谱的意义上该是什么形状」。

2. 奇异值与曲率：先分清两个矩阵

一张权重矩阵 W 的梯度 G = ∂L/∂W 也是矩阵。对 G 做奇异值分解 G = UΣVᵀ，得到的是一组带权重的秩一方向 uᵢvᵢᵀ：σ 大表示梯度矩阵的更多能量集中在这些方向上。它不等同于损失曲面在这些方向上的曲率。

描述局部曲率的是 Hessian H = ∂²L/∂θ²。只有在这类二阶模型里，才能把最大特征值与稳定步长直接联系起来。梯度矩阵的奇异值和 Hessian 的特征值回答的是不同问题，不能由前者推出「学习率最多到 1/σ」。

下面单独用一个二次损失理解曲率条件数：L = ½(λ₁x₁² + λ₂x₂²)。梯度下降在特征方向上的更新是 xᵢ ← (1 − ηλᵢ)xᵢ，稳定要求 0 < η < 2/λmax。假设 λ₁ = 100、λ₂ = 1：

  • 步长受最陡方向限制；取 η = 1/100 时，该方向一步归零。
  • 同一学习率下，平缓方向每步只衰减 1%，需要约一百步才能接近原点。

这就是病态曲率的实际后果：不同方向的合适步长差得很大，而共享学习率必须兼顾最陡方向。这个例子解释预条件的动机，但不是 Muon 更新矩阵奇异值的直接证明。

条件数怎么拖慢收敛

两条分量的初值都是 0.9。步长取「陡方向能承受的最大值」，于是陡方向一步归零，平方向按固定比例慢慢衰减。拖动滑块改变 Hessian 的曲率比。

Adam 的预条件是逐坐标的：它给每个参数单独一个缩放系数。如果曲率主轴恰好沿着坐标轴，这种对角缩放量身合适；如果主轴相对坐标轴旋转，对角预条件就不能完整校正它。

Muon 关注的是另一个对象：把二维参数的动量更新矩阵做近似正交化，让不同奇异方向的更新尺度更接近。这是更新几何的改变，不意味着它已经求出了 Hessian，也不保证泛化一定更好。

3. Newton–Schulz 迭代是什么

以常见的 Muon 实现为例，先形成动量矩阵 M，再近似求它极分解里的正交因子 U Vᵀ，其中 M = U Σ Vᵀ。不同实现会改变动量、归一化与缩放细节，不能把所有变体都简化成「直接正交化当前梯度」。

精确的极分解会丢掉 Σ：满秩时 UVᵀ 的奇异值全部为 1。NS 迭代只是逼近这个目标，因此实际输出不会严格满足这一性质。

直接做 SVD 往往太贵，也不好批处理。Muon 因此改用主要由矩阵乘法组成的迭代。经典 Newton–Schulz 形式是：

X ← ½ · X · (3I − XᵀX)

它与矩阵逆平方根的迭代相关，在合适的初始化和收敛区间内具有二次收敛性；实际实现需要先归一化，不能假设任意初始谱都能收敛。

常见 Muon 实现使用的是一条经过调节的五次多项式：

X ← aX + b(XXᵀ)X + c(XXᵀ)²X
a = 3.4445　b = −4.7750　c = 2.0315

迭代 5 次，没有显式分解或求逆，主要是 GEMM。它的系数刻意不追求缓慢、精确地收敛到 1，而是让奇异值较快进入一个较窄的范围。

所以结果既不是精确的 UVᵀ，也不是所有奇异值都等于同一个常数。参考实现描述的范围约为 0.68–1.13；重要的是近似正交化和相对尺度的调整，整体尺度还要由后续学习率与形状因子处理。

至于 5 步够不够，2026 年有一篇工作专门测了这件事（Spectral Scaling Laws of Muon）。研究跟踪的是动量矩阵的谱：中浅层随模型规模变化温和（约 M^−0.25），5 步在更大规模上仍可能够用；部分靠后的层变化更剧烈（最高到 M^−0.96），到前沿规模可能进入 NS 难以校正的区域，需要增加迭代或重调系数。

4. Muon 的学习率语义

这是从 AdamW 迁过来最容易踩的一脚：两个 lr 不是同一个量纲，不能直接换算。

AdamW 的更新是 m / (√v + ε)。由于除以了梯度的均方根，更新被归一化了——每个参数每步的位移大致就是 η，与梯度大小无关。所以 AdamW 的 lr 是一个逐参数的步长。

Muon 的理想正交化目标是 UVᵀ；满秩时它的谱范数等于 1。这说的是整个矩阵的尺度，不是单个元素的尺度，实际 NS 输出只是近似满足。

两者之间差着一个形状因子。一个 m×n 的满秩矩阵，如果所有奇异值都是 1，那么它的元素均方根是：

RMS = √(rank / (m·n)) = 1 / √(max(m, n))

也就是说，同样一步，4096×4096 的矩阵每个元素只动 1/64，而 256×256 的动 1/16。差了四倍，只因为形状不同。

所以实现里必须乘一个尺度因子，常见的是：

scale = 0.2 · √(max(m, n))

乘完之后元素 RMS 变成 0.2，与形状无关了。这时候 Muon 的等效步长才可比——但它仍然不是 AdamW 的 η，需要单独标定。

还有一处同样不能照搬：权重衰减。AdamW 里的 wd 是相对于「更新 RMS ≈ η」定义的；Muon 的更新 RMS 是另一个数，直接搬过来衰减力度就变了。Moonshot 在把 Muon 推到 3B/16B 规模时补的关键一步，就是把 wd 重新标定到与 AdamW 的更新 RMS 匹配。

5. 余弦衰减是什么，为什么用它

学习率随训练进度变化，最常见的一条曲线是：

η(t) = η_min + ½(η_max − η_min)(1 + cos(π·t/T))

t 从 0 走到 T，η 从 η_max 平滑降到 η_min。形状像一个缓慢的「S」：开头掉得慢，中段掉得快，结尾又慢下来。

为什么是这条曲线？三个理由。

开头要慢降，因为大学习率的价值在于探索——在损失面上走得更远，躲开差的初始化。这时候降太快，等于提前放弃探索。

结尾也要慢降，因为小学习率的价值在于稳定——让参数在极小值附近沉下来，而不是被梯度噪声推着到处晃。余弦在 t=T 处的导数为零，正好给出一个平滑的收尾。

它没有额外的超参。阶梯衰减要你决定「第几轮降、降多少」，余弦只要一个总步数 T，剩下的交给曲线。这也是它在实践中流行的实际原因。

它通常和 warmup 搭配：最前面几百步把 lr 从零线性拉起来。原因是 Adam 的二阶矩估计在最初几步还很粗糙，此时用满学习率容易把参数推飞。

不过余弦也有被质疑的地方：它把 lr 衰减到接近零，最后一大段步数其实走不了多远。于是近几年大模型训练里更流行 warmup + 稳定 + 末尾衰减（WSD）——中间保持恒定，只在最后一段降。好处是可以在稳定段任意截断一个 checkpoint 继续训练，不必为每次延长重新规划整条曲线。

6. 什么情况下别用

几条边界，都是实践中会撞上的。

第一，常见实现主要处理二维矩阵参数。embedding、输出层、偏置和归一化层通常交给 AdamW；卷积权重若要使用，需要先明确摊平成二维的方式。这是当前算法与实现的适用边界，不是说这些参数在数学上绝无其他正交化方案。

第二，超参不能直接照搬。lr 和 wd 的语义变了，沿用 AdamW 数值而不重新标定，容易得到不同的更新与衰减力度。

第三，NS 是近似。很小的奇异值可能难以被有限次迭代有效校正，规模和层类型变化时都应检查实际谱与更新质量。

第四，短程微调未必值得换。Muon 的公开优势主要来自较大规模、较长训练；几百步微调是否有收益，要在同数据、同评测协议下实测，不能预先保证。

7. 收尾

回到开头那句话：优化器的差别在于用哪把尺子。

SGD 用欧氏距离，Adam 用逐坐标的尺度，Muon 用矩阵的谱。三者的演进方向是一致的——让尺子更贴近问题本身的结构。

但尺子再好，也只是让每一步更有效。它不改变「要多少步才够」这件事，也不改变数据质量决定上限这件事。
