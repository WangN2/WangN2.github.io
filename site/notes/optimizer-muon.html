优化器与 Muon

优化器之间的差别，说到底只有一件事：用什么样的尺子，去量「这个方向有多陡」。

2026-10-29约 7 分钟训练方法全系列 ›

起因是看到一个训练配置里写的是 Muon 而不是 AdamW。于是把这条线梳理了一遍：奇异值到底在说什么、Newton–Schulz 是什么、学习率为什么不能照搬、余弦衰减又在干什么。

1. 先看都有哪些优化器

梯度是一个向量，但「往哪走、走多远」取决于你怎么定义距离。换了尺子，最速下降的方向就变了。按这把尺子分类，现有的优化器大致是这么几档：

尺子代表更新式
欧氏距离SGD、动量、NesterovΔ = −η·g
逐坐标缩放AdaGrad、RMSProp、Adam / AdamW、LionΔ = −η·m / (√v + ε)
行与列的低秩近似Adafactor、Shampoo、SOAP用 Kronecker 因子做预条件
矩阵的谱结构MuonΔ = −η·U Vᵀ
二阶曲率估计Sophia、K-FAC用曲率替换学习率

AdamW 仍然是默认答案。想换的动力一般只有三个：省显存、省算力，或者在大规模上拿到更好的缩放。

Muon 属于第四类。它不问「每个参数该走多大」，它问「这张权重矩阵的更新，在谱的意义上该是什么形状」。

2. 奇异值：少数几个方向特别陡，是什么意思

先把一句话拆开看：神经网络的梯度矩阵通常很病态，少数几个方向的奇异值极大，其余极小。

一张权重矩阵 W 的梯度 G 也是个矩阵。矩阵可以理解成一个「线性变换」：给它一个输入方向，它输出一个方向，并把这个方向的长度乘上一个倍数。这个倍数就是奇异值。

所以 σ 大，意味着：沿着那个输入方向稍微动一动权重，这一层的输出就会剧烈变化，损失跟着剧烈变化。反过来，σ 很小意味着那个方向上怎么动，损失几乎没反应。

一个具体的例子。假设某层只有两个方向，σ = 100 和 σ = 1。你用梯度下降：

  • 步长被最陡方向限制死。走大了，那个方向直接发散，所以学习率最多到 1/100 量级。
  • 在最陡方向上，一步就能走到底。
  • 在平的方向上，每步只挪 1% 的距离，要走一百步。

这就是「病态」的实际后果：不是慢，是快慢差了一百倍，而你只能按最慢的那个来定步长。

条件数怎么拖慢收敛

两条分量的初值都是 0.9。步长取「陡方向能承受的最大值」，于是陡方向一步归零，平方向按固定比例慢慢衰减。拖动滑块改变曲率比。

有一段话值得单独说，因为它解释了为什么这件事值得修。

陡的方向，往往是已经学会的东西；平的方向，才是还没学会的。梯度的大小衡量的是「这里的损失对参数有多敏感」，不是「这里还差多少要学」。已经拟合好的方向，梯度照样很大；真正欠拟合的方向，梯度反而很小。

结果就是：梯度下降把绝大部分更新预算，花在了给已经做对的事情继续加码上。

那 Adam 为什么不够？因为 Adam 的预条件是逐坐标的——它给每个参数单独一个缩放系数。如果病态恰好沿着坐标轴，它确实能修好。但如果那几个陡方向是相对于坐标轴斜着的，逐坐标缩放就看不见它们。这是对角预条件的固有局限。

Muon 的做法是：不要逐坐标，直接把这整张矩阵的谱拉平。

3. Newton–Schulz 迭代是什么

目标很明确：给定梯度矩阵 G，求它的极分解里那个正交因子 U Vᵀ。其中 G = U Σ Vᵀ。

注意这一步做了什么：把 Σ 丢掉了。保留下来的 UVᵀ，所有奇异值都等于 1——每个方向等权。

问题是，正儿八经做 SVD 太贵。GPU 上的 SVD 既慢，又不好批处理，还吃不到张量核的算力。于是改用迭代逼近。

经典的 Newton–Schulz 迭代长这样：

X ← ½ · X · (3I − XᵀX)

它是「牛顿法求矩阵逆平方根」的矩阵版本。收敛是二次的——误差在一步之内平方——但有个前提：初始的奇异值要接近 1。差得远就不收敛。

所以 Muon 用的不是这个原版，而是一条五次多项式，系数是调出来的：

X ← aX + b(XXᵀ)X + c(XXᵀ)²X
a = 3.4445　b = −4.7750　c = 2.0315

迭代 5 次。整个过程只有矩阵乘法——没有分解，没有求逆，全是 GEMM，能在张量核上跑。

可以把这条多项式理解成一条「把数值往 1 推」的曲线：落在一定范围内的奇异值，每迭代一次就更靠近 1。迭代 5 次，足够把常见的谱压平。

有一个细节容易被忽略：结果不必精确等于 1。多项式的不动点不是 1，五步之后所有奇异值会落到同一个常数上。这就够了——重要的是它们彼此相等，整体那个常数会被学习率的尺度因子吸收掉。

至于 5 步够不够，2026 年有一篇工作专门测了这件事（Spectral Scaling Laws of Muon）。结论是分层的：中浅层的谱随模型规模变化温和（约 M^−0.25），5 步在更大规模上依然够用；但部分靠后的层变化很剧烈（最高到 M^−0.96），到前沿规模会掉进「NS 推不动」的区域，需要增加迭代或重调系数。

4. Muon 的学习率语义

这是从 AdamW 迁过来最容易踩的一脚：两个 lr 不是同一个量纲，不能直接换算。

AdamW 的更新是 m / (√v + ε)。由于除以了梯度的均方根，更新被归一化了——每个参数每步的位移大致就是 η，与梯度大小无关。所以 AdamW 的 lr 是一个逐参数的步长。

Muon 的更新是 UVᵀ，它的谱范数等于 1。这说的是整个矩阵的尺度，不是单个元素的尺度。

两者之间差着一个形状因子。一个 m×n 的矩阵，如果所有奇异值都是 1，那么它的元素均方根是：

RMS = √(rank / (m·n)) = 1 / √(max(m, n))

也就是说，同样一步，4096×4096 的矩阵每个元素只动 1/64，而 256×256 的动 1/16。差了四倍，只因为形状不同。

所以实现里必须乘一个尺度因子，常见的是：

scale = 0.2 · √(max(m, n))

乘完之后元素 RMS 变成 0.2，与形状无关了。这时候 Muon 的等效步长才可比——但它仍然不是 AdamW 的 η，需要单独标定。

还有一处同样不能照搬：权重衰减。AdamW 里的 wd 是相对于「更新 RMS ≈ η」定义的；Muon 的更新 RMS 是另一个数，直接搬过来衰减力度就变了。Moonshot 在把 Muon 推到 3B/16B 规模时补的关键一步，就是把 wd 重新标定到与 AdamW 的更新 RMS 匹配。

5. 余弦衰减是什么，为什么用它

学习率随训练进度变化，最常见的一条曲线是：

η(t) = η_min + ½(η_max − η_min)(1 + cos(π·t/T))

t 从 0 走到 T，η 从 η_max 平滑降到 η_min。形状像一个缓慢的「S」：开头掉得慢，中段掉得快，结尾又慢下来。

为什么是这条曲线？三个理由。

开头要慢降，因为大学习率的价值在于探索——在损失面上走得更远，躲开差的初始化。这时候降太快，等于提前放弃探索。

结尾也要慢降，因为小学习率的价值在于稳定——让参数在极小值附近沉下来，而不是被梯度噪声推着到处晃。余弦在 t=T 处的导数为零，正好给出一个平滑的收尾。

它没有额外的超参。阶梯衰减要你决定「第几轮降、降多少」，余弦只要一个总步数 T，剩下的交给曲线。这也是它在实践中流行的实际原因。

它通常和 warmup 搭配：最前面几百步把 lr 从零线性拉起来。原因是 Adam 的二阶矩估计在最初几步还很粗糙，此时用满学习率容易把参数推飞。

不过余弦也有被质疑的地方：它把 lr 衰减到接近零，最后一大段步数其实走不了多远。于是近几年大模型训练里更流行 warmup + 稳定 + 末尾衰减（WSD）——中间保持恒定，只在最后一段降。好处是可以在稳定段任意截断一个 checkpoint 继续训练，不必为每次延长重新规划整条曲线。

6. 什么情况下别用

几条边界，都是实践中会撞上的。

第一，只适用于二维权重。embedding、输出层、偏置、归一化层一律交给 AdamW。embedding 稀疏且非平稳，正交化没有意义；卷积层则要先摊平成二维。

第二，超参不能迁移。lr 和 wd 的语义都变了，照搬一定出问题。

第三，NS 是近似。小奇异值推不动就是推不动，规模越大、层越深，越要检查这件事。

第四，小数据微调不值得。收益来自大规模长训练，几百步的微调里，优化器的差别会被「训练量本身不够」盖过去。

7. 收尾

回到开头那句话：优化器的差别在于用哪把尺子。

SGD 用欧氏距离，Adam 用逐坐标的尺度，Muon 用矩阵的谱。三者的演进方向是一致的——让尺子更贴近问题本身的结构。

但尺子再好，也只是让每一步更有效。它不改变「要多少步才够」这件事，也不改变数据质量决定上限这件事。
