NOTE 04 / 视觉标定 · 外参

手眼标定：
把「相机看到的」
搬进机器人坐标系

标签给你「标签相对相机」，运动学给你「末端相对基座」。这两个数都很准，但拼不到一起——中间缺一个数：相机到底装在机器人的哪个位置。

2026-10-23约 5 分钟视觉标定全系列 ›

上一篇解决了「看到标签，怎么算出它在相机里的六自由度位姿」。这一篇解决下一个问题：相机在机器人身上，它看到的位姿怎么搬进机器人的坐标系。搬不过去，视觉就只是一堆好看的坐标。

范围。本文只讲外参的求法与验证，不涉及相机内参标定（焦距、畸变）、时间同步和多相机融合。内参是另一个独立问题，搞混了两者的误差会互相甩锅。

1. 你需要的那个数，谁也不给你

把三个已知量摆出来：

T_cam_tag　相机看到标签　← 视觉（PnP）
T_base_ee　末端在基座系　← 机器人正运动学
T_base_cam　相机在基座系　← ？

要把标签位置告诉机器人，需要的是 T_base_tag，它由三者串起来：

T_base_tag = T_base_cam · T_cam_tag

而相机装在末端上时，还要多一层：

T_base_tag = T_base_ee · T_ee_cam · T_cam_tag

中间那个 T_ee_cam（或相机固定时的 T_base_cam）就是外参。它不会从任何一次观测里自动掉出来——你把它猜错 2 厘米，末端就会偏 2 厘米，而且偏移方向会随着机器人姿态旋转，表现为「时准时不准」。

2. 两种装法，两套方程

装法未知量特点
眼在手上
相机装在末端，跟着动		T_ee_cam可以凑近看细节，视野随臂移动；标定要在多个姿态下进行，相机自身的运动被算进方程里
眼在手外
相机固定在工作单元上		T_base_cam视野固定、不随臂动，适合盯住整个工装；但臂挡视线、标定范围受视野限制

两者的方程形式一样，区别只在于「哪一头是已知的」。下面的推导按眼在手上写，眼在手外只需把末端换成基座。

3. AX = XB：两条路径必须到同一个地方

让机器人从姿态 1 动到姿态 2。记：

  • A：末端从姿态 1 到姿态 2 的运动（T_ee1_ee2），由运动学直接读出；
  • B：相机看到的标签运动（T_cam1_tag · T_cam2_tag⁻¹），由视觉给出；
  • X：相机相对末端的固定变换，也就是要求的外参。

因为相机是刚接在末端上的，这两段运动在「末端坐标系」里描述的是同一件事，于是：

A · X = X · B

换成一句话：从末端走到相机，可以经 A 再经 X，也可以经 X 再经 B，两条路必须落到同一个地方。 这就是全部推导。剩下的工作，是拿足够多的姿态把 X 解出来，并验证它在每个姿态上都成立。

下面的实验把这两条路径画出来。拖动滑块改变机器人的姿态，或者给标定结果加一点误差，看两条路径从哪里开始分叉。

路径一致性

蓝线是「末端 → 相机」这条路，橙线是「标签 → 相机」这条路。标定正确时，两条线终点重合；加一点误差，终点就分开——分开的距离，就是这个姿态下的残差。

4. 先解旋转，再解平移

A·X = X·B 里的旋转和平移是解耦的。把两边写成旋转加平移：

R_A · R_X = R_X · R_B　　　　（只含旋转）
R_A · t_X + t_A = R_X · t_B + t_X　（只含平移）

第一式与平移无关，所以先解 R_X：每一组姿态给一个约束，多组姿态联立即可。常见做法有两种——

思路怎么做注意
两两配对（经典两段式）两组姿态的旋转轴叉乘，得到旋转的约束，再用 SVD 求最近的正交阵姿态对之间旋转轴越「不平行」，约束越强
整体最小二乘 / 非线性优化把所有姿态一起丢进优化器，直接最小化残差实现简单，但需要好的初值，否则容易掉进局部极小

拿到 R_X 之后代回第二式，它就变成了关于 t_X 的线性最小二乘——这一步没有迭代，也没有初值问题。

5. 为什么「多转几个角度」不是废话

手眼标定最容易失败的三个原因，全都跟「姿态够不够丰富」有关：

退化情况为什么解不出来
只做平移，不转旋转方程退化为 0 = 0，R_X 完全不受约束
所有姿态绕同一根轴转绕轴的分量有解，垂直方向无解——解出的 R_X 只在部分方向上可信
角度变化太小数学上有解，但噪声被放大，条件数很差；表面看误差不大，换到工作空间边缘就暴露

实践上的做法：让每个姿态的旋转轴都不同，并让旋转轴之间的夹角尽量大。取姿态时不要只在一个平面里转，也不要只转手腕——把大臂、躯干一起用上，姿态差异才够大。

6. 怎么验证标定结果

解出来不等于对了。三个逐级加强的检查：

  1. 残差。把解出的 X 代回每一组姿态，看 A·X 与 X·B 差多少。残差大说明数据或模型有问题；残差小但不均匀，说明某些姿态在拖后腿。
  2. 闭环。用标定结果把标签位姿搬回基座系，再让机器人末端去碰同一个点。这一步会把内参、外参、运动学误差一起暴露出来——它测的不是标定，是整条链路。
  3. 换位重测。把标签挪到工作空间另一个位置再测一次。如果误差随位置线性增长，多半是尺度或内参；如果误差随姿态变化，多半是外参。

还有一条容易被忽略：标定结果要写下日期和姿态集合。换了相机支架、撞过一次、拧过一颗螺丝，这组数就不作数了——但它不会自己失效，只会在某次抓取失败时才提醒你。

7. 它在这条链路上的位置

这几篇笔记是串起来的，外参正好是其中一环：

环节由谁提供用在哪里
末端相对基座正运动学标定的 A 段、抓取时的末端位姿
标签相对相机AprilTag 与 PnP标定的 B 段、运行时的盘位姿
相机相对机器人本文（外参）把上面两个接起来
盘位姿到抓取点料盘抓取的重算链每次运行的四站目标
底盘怎么走过去全向底盘运动学把机器人送到工位

反过来读这张表也成立：下游任何一环出问题，都要先确认外参没过期。 「时准时不准」这种症状，优先怀疑外参，而不是先调算法。
