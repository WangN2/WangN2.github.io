# WangN2 个人网站第一版设计

状态：用户已审阅并回复“设计通过”。尚未实现、推送或发布。

## 目标

建立「WangN2 · 机器人技术笔记」个人网站，使用 GitHub Pages 托管。
访客进入主页即可操作 G2 全身运动学演示，不需要安装 ROS、Isaac Sim 或登录账号。
先完成本地预览，用户确认页面后才进入公开发布步骤。

## 已确认的内容与边界

- 公开昵称：WangN2。简介：记录机器人运动控制、导航与仿真的学习和实践。
- 风格：简洁浅色、蓝色点缀；适配桌面和手机。
- 主页包含个人介绍、直接嵌入的 G2 交互演示、技术笔记入口。
- 首篇文章为「从关节角到末端运动：正运动学与雅可比」，仅使用已有演示支持的知识和结果。
- 不编造履历、文章、项目成果、联系方式或真机验证结论。
- 不包含公司身份、内部项目、扫描场景、服务器地址、个人本地路径或认证信息。
- 第一版不做账号、评论、数据库、统计追踪、广告或商业化功能。

## 页面与交互

### 主页

页首显示网站标题与三个锚点：介绍、交互实验室、技术笔记。
简介后直接展示 G2 演示，而不是只有截图或外部跳转链接。
演示旁提供「独立大屏打开」入口，手机端控件自动换行，页面正常纵向滚动。
技术笔记区只展示已写好的首篇文章；页脚提供 GitHub 链接、资产署名和许可入口。

### G2 演示页

复用已有验证的运动学内核和模型，保持以下能力：

- 左右臂各 7 轴、躯干 5 轴、头部 3 轴的单轴调节和模型限位。
- 两侧夹爪通过主轴和闭链样本联动，不把被动关节暴露成独立硬件指令。
- 全向底盘前后、横移、转向；显示舵轮转向与滚动。
- 单关节正负 3 度、末端世界坐标 XYZ 正负 5 cm、轨迹和雅可比预测。
- 全身与局部视角、拖动旋转、缩放、停止、姿态预设。
- 显示教学运动学边界：无碰撞、重力、夹持力或真机连接；末端位置控制不保持朝向。

默认姿态为站立、双臂下垂，不自动启动运动。独立页面提供返回主页入口。
保留重要误差读数和失败状态，不将未收敛目标显示为成功。

### 技术笔记

用初学者可理解的语言说明模型来源、正运动学、雅可比局部近似、阻尼逆解和演示限制。
文章链接回交互实验室；不引用内部仿真场景和生产控制代码。

## 技术方案

采用无需后台的 HTML、CSS、JavaScript 静态站点，不引入博客框架。
展示功能已经存在，第一版重点是安全整理、嵌入和发布适配。
完整博客框架作为未来文章数量增加后的选择，不作为本版依赖。

仓库分为可发布文件与维护文件：

```text
site/
  index.html
  demos/g2/index.html
  notes/kinematics.html
  assets/                 样式、脚本、精简模型和第三方渲染库
  licenses/               模型与第三方依赖许可
scripts/                  构建和公开内容检查
tests/                    数值、页面和浏览器回归
docs/superpowers/          设计与实施计划
```

主页使用同站点 iframe 加载独立演示页，避免两套三维渲染代码。
iframe 高度跟随内容，防止控件截断；如果通过消息同步高度，父页验证来源窗口、来源域和消息结构。
本地预览通过只监听回环地址的静态 HTTP 服务进行，不依赖 file 协议特例。

Three.js 固定为既有演示使用的版本，放在同站点 assets 中，保留许可。
运行时不请求第三方 CDN、公司服务或模型下载接口。
模型和界面不依赖 Codex 的 window.openai；若保留姿态记忆，仅存浏览器本地，并提供可用的默认状态。
不支持 WebGL、解压能力不足或模型加载失败时显示中文错误提示，不留空白画面。

未来发布只上传 site/ 的静态文件，使用 GitHub Pages 的静态产物发布方式。
本地预览阶段不添加会自动公开部署的工作流，不开启 Pages，不推送代码。

## 验证与验收

1. 既有 19 项数值和接口检查迁移后通过；不改变机械连接、限位和闭链计算语义。
2. 浏览器验证双臂末端移动、躯干/头部独立性、左右夹爪、底盘平移/旋转、停止和状态恢复。
3. 验证主页内嵌演示与独立演示页均能操作，文章和导航链接可用。
4. 在 360 px 手机宽度与桌面宽度检查页面，无横向溢出、控件截断或控制台异常。
5. 关闭外网资源访问后，在本地 HTTP 服务中仍能加载并操作模型，证明运行时资源已同站点化。
6. 公开内容扫描包括压缩模型解码结果，禁止出现内部路径、密钥、webhook 和公司场景资产。
7. 向用户交付本地预览、测试结果及发布目录清单；发布需在之后单独确认。
